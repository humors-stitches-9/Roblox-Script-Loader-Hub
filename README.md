## FAQ

### What is XCutors?

XCutors is a curated collection of popular Roblox script executors packaged with a universal loader for easy access and management.

### Which executors are included?

The pack includes Volt, Synapse Z, Potassium, Wave, and a universal loader called xcutorsLoader.

### Is this compatible with my Windows version?

XCutors supports Windows 10 and Windows 11. Ensure your .NET runtime is up to date.

### How do I switch between executors?

Use the universal loader interface to select your preferred executor from the dropdown menu and click Load.

### Do I need to install each executor separately?

No. The universal installer handles all executor installations automatically during first setup.

### How do I import custom scripts?

Open the Script Manager tab, click Import, and select your .lua file. It will be saved to your local library.

### What if an executor stops working after a Roblox update?

Check for XCutors updates in the Settings tab. We typically release compatibility patches within 24–48 hours.
